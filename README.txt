ARTESANO TACO CATERING WEBSITE
==============================

FILES
-----

index.html
    Main website page and catering quote form.

styles.css
    All website styling, responsive layout, animations,
    colors, buttons, navigation, and form styling.

script.js
    Mobile navigation, catering/wedding form behavior,
    form validation, and scroll animations.


HOW TO OPEN THE WEBSITE IN VS CODE
----------------------------------

1. Extract the artesano-catering-site.zip file.

2. Open Visual Studio Code.

3. Go to:
   File > Open Folder

4. Select the "artesano-catering-site" folder.

5. Install the "Live Server" extension if you do not
   already have it.

6. Open index.html.

7. Right-click anywhere inside index.html.

8. Select:
   "Open with Live Server"

The website should open in your browser.

ARTESANO TACO WEBSITE DEMO
==========================

PAGES
-----
index.html       New home page demo
catering.html    Catering quote page
styles.css       Styling for both pages
script.js        Navigation, animations and form demo behavior

RUN IN VS CODE
--------------
1. Open this folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click index.html.
4. Choose "Open with Live Server".

DEMO NOTES
----------
